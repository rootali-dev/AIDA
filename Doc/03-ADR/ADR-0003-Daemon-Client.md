# ADR-0003: تفکیک ابزار CLI از Daemon پس‌زمینه از طریق Unix Socket

- **تاریخ:** 2026-08-14
- **وضعیت:** تایید شده (Accepted)

## زمینه و صورت مسئله (Context)
اجرای مانیتورینگ و موتور هوش مصنوعی در یک فایل باینری تکی CLI باعث می‌شد با بستن ترمینال، سرویس دفاعی متوقف شود.

## تصمیم اتخاذ شده (Decision)
جداسازی کامل دیمن `ai-idad` به عنوان سرویس سیستمی و ارتباط با کلاینت سبک `ai-idactl` از طریق IPC سوکت یونیکس.

# ADR-0002: استفاده از LRU_PERCPU_HASH برای جلوگیری از سرریز حافظه

- **تاریخ:** 2026-08-14
- **وضعیت:** تایید شده (Accepted)

## زمینه و صورت مسئله (Context)
مپ‌های استاندارد `PERCPU_HASH` تحت حملات جعل آدرس IP پر شده و تخصیص‌های بعدی را با خطای شکست مواجه می‌کنند.

## تصمیم اتخاذ شده (Decision)
استفاده اجباری از `BPF_MAP_TYPE_LRU_PERCPU_HASH` تا پاکسازی کلیدهای قدیمی به صورت بومی و بدون قفل توسط خود کرنل انجام شود.



## how to create .venv **virtual environment**  

1. اول از کامند زیر برای ساخت یک venv model استفاده میکنیم 
```
python -m venv /path/to/new/virtual/environment
```
2.  اموزش کامل تر رو میتونی از [docs.python](https://docs.python.org/3/library/venv.html) ببینی
3. با کامند زیر میتونیم توی لینوکس و کامند بعدی توی ویندوز وارد محیط مجازی بشیم
```
Linux: source venv/bin/activate
Windows: venv\Scripts\activate
```
4. با کامند زیر میتونیم پکیچ ها و لایبری های مختلف پاییتون رو نصب بکنیم و مدیریت بکنیم
```
pip install ***   
```

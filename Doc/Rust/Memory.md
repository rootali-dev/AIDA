
# مفاهیم کنترل مموری 

توی زبان‌هایی مثل پایتون تو فقط می‌نویسی `x = 5`. اما توی زبان‌های سیستمی مثل Rust و C++، سیستم‌عامل باید دقیقاً بدونه **چند خانه از حافظه (RAM)** رو باید به این متغیر اختصاص بده.

حروفی مثل `u8` یا `i32` از دو بخش تشکیل شدن:

1. **حرف اول (`u` یا `i`):**
    
    - **`u` یعنی Unsigned (بدون علامت / فقط مثبت):** اعداد فقط از $0$ شروع میشن به بالا. (نمی‌تونه منفی باشه).
        
    - **`i` یعنی Signed (علامت‌دار):** هم اعداد منفی رو شامل میشه هم مثبت (مثل $-5$ یا $+5$).
        
2. **عدد بعدی (تعداد بیت‌ها در حافظه):**
    
    تعداد بیت‌هایی که اون متغیر در حافظه اشغال می‌کنه ($8$ بیت، $16$ بیت، $32$ بیت یا $64$ بیت).
    

### 📊 جدول راهنمای متغیرهای عددی:

|**نام متغیر**|**اندازه در حافظه**|**بازه اعدادی که نگه می‌داره**|**کاربرد واقعی در شبکه و eBPF**|
|---|---|---|---|
|**`u8`**|۱ بایت ($8$ بیت)|$0$ تا $255$|یک بایت خام از پکت، یا یک عدد کوچک مثل پروتکل (TCP=6)|
|**`u16`**|۲ بایت ($16$ بیت)|$0$ تا $65,535$|**پورت‌های شبکه** (مثلاً پورت $80$ یا $443$)|
|**`u32`**|۴ بایت ($32$ بیت)|$0$ تا $4,294,967,295$|**آدرس‌های IPv4** (چون IPv4 دقیقاً از ۴ بایت تشکیل شده)|
|**`u64`**|۸ بایت ($64$ بیت)|اعداد بسیار بزرگ|تایمرها یا تعداد بایت‌ها/پکت‌های شمارش‌شده|

> 💡 **چرا آدرس IP یک `u32` است؟**
> 
> آدرس `192.168.1.1` از ۴ بخش تشکیل شده که هر بخش یک `u8` است (بین $0$ تا $255$). وقتی این ۴ بایت رو کنار هم بذاریم، میشه یک عدد ۳۲ بیتی یا همون `u32`!

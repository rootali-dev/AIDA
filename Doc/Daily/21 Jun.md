### نتیجه تا زمان فعلی(۱۱:۲۵)
تلاش برای ساخت دو بخش اصلی پروژه هست XDP و user space 
تا الان با نگاه کردن به نتایج هوش مصنوعی و بنچ مارک های برای بخش XDP یا kernal 
### زبان XPD
نتایج نشون میده زبان C برای این بخش به مقدار ۰.۵٪ سریع تره نزدیک به ۲ تا ۳ نانو ثانیه اما زبان rust با سیستم مالکیت (Ownership) و پوینتر های امنی که داره باعث میشه قبل از کامپایل کد خودت کامپایلر راست ۹۹ درصد مشکلات پوینتر و خطاهای حافظه رو تشخیص بده که خیلی کمک میکنه توی تایید شدن کد برای Verifier

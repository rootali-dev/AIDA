
### programmed I/O
 
اگر بخوایم  فرض بکنیم DMA وجود نداره ما وارد حالتی میشم به اسم PIO که مخفف programmed I/O هست تفاوت اصلی نهوه دسترسی به حافظه هست وقتی ما از PIO استفاده میکنیم در اصل این فرایند تی میشه

پکت در FIFO Buffer ذخیره میشود ---> کارت شبکه به CPU اطلاع میدهد ---> پردازنده باید ریچسترها را ذخیره کند و خط به خط بایت های پکت رو از داخل کارت شبکه بخواند و داخل رم بنوسید

ولی وقتی از DMA استفاده میکنیم فرایند کامل تغیر میکنه

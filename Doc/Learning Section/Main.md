# پردازش پکت داخل کرنل 

- یادگیری نفهوه استفاده از تابع `XdpContext` و کدنویسی و درک مهفوم `Bounds Checking` 


### عبارت های کلیدی که برای سرچ کمکمون میکنه 

  - `Aya XdpContext data and data_end`
    
- `eBPF verifier bounds checking in Rust`
    
- `Parsing network headers (Ethernet, IPv4, TCP) in Aya` 

**کتابخانه‌های پیشنهادی برای مطالعه:** نگاه کردن به کدهای ریپازیتوری `network-types` در راست که ساختار هدرهای استاندارد مثل `Ipv4Hdr` و `TcpHdr` رو آماده داره. 

### بخش ۳: ساخت مپ‌ها در Aya

ما نیاز به یک مپ داریم تا شماره پورت‌های بلاک شده رو توش ذخیره کنیم. نوع `HashMap` برای این کار عالیه.

- **عبارات کلیدی برای سرچ:**
    
    - `Aya ebpf HashMap macro #[map]`
        
    - `Shared BPF maps between Rust and Go`
        
- **نکته برای یادگیری:** ببین چطور ماکروی `#[map(name = "BLOCKED_PORTS")]` در راست، یک سکشن در فایل خروجی ایجاد می‌کنه.


### بخش ۴: لایه کاربر با Go (User Space)

حالا راست کارش تموم شده و یک فایل بهت داده مثلاً به اسم `firewall.bpf.o`. حالا نوبت Go هست. برای ابزار Go بهترین و استانداردترین کتابخانه دنیا `cilium/ebpf` هست.

- **داکیومنت اصلی:** مستندات وب‌سایت **ebpf-go.dev** (توسط تیم سیلیکوم نگهداری میشه).
    
- **عبارات کلیدی برای سرچ:**
    
    - `cilium/ebpf LoadCollectionSpec` (چطور فایل ELF تولید شده توسط زبان دیگه رو توی Go لود کنیم؟)
        
    - `cilium/ebpf attach XDP to interface`
        
    - `Golang ebpf map update / delete`
        
- **مفهوم عمیق:** در Go چطور ساختار داده‌ای مپ رو تعریف کنی که دقیقاً با سایز کلید و مقداری که در راست نوشتی همخوانی داشته باشه (مثلاً `uint16` برای پورت در Go با `u16` در راست).

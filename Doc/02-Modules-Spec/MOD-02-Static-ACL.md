# ماژول MOD-02: فیلتر استاتیک پورت‌ها (Static ACL Filter)

- **زیرسیستم:** Ingress Fast-Path
- **ساختار داده:** `BPF_MAP_TYPE_ARRAY`
- **اولویت:** #p0

## مشخصات مپ
- اندازه: 65536 خانه (16-bit L4 Port Space)
- نوع مقدار: `u8` (0 = DROP, 1 = PASS)
- هزینه پردازش: $O(1)$ با دسترسی مستقیم به حافظه آرایه بدون هشینگ.

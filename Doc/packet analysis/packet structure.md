

چیدمان یک پکت استاندارد  (ethernet frame) در کابل شبکه به این صورت چیده شده هست
‍```
``` 
 ┌─────────────────┬─────────────────┬─────────────────┬───────────────────────┬
 │   Layer 2 (L2)  │   Layer 3 (L3)  │   Layer 4 (L4)  │   Layer 7 (Payload)   | 
 │   Ethernet Header│    IP Header   │  TCP/UDP Header │     Application Data  | 
 ├─────────────────┼─────────────────┼─────────────────┼───────────────────────|
 │     14 Bytes    │  20-60 Bytes    │   8-60 Bytes    │      Variable Size    │ 
 └─────────────────┴─────────────────┴─────────────────┴───────────────────────┴
```

البته یک بخش دیگه در انتهای انترنت فریم وجود دارد به اسم FCS که توسط سخت افزار شبکه برسسی و حذف میشود و ۴ بایت حجم دارد

### 🔹 لایه ۲: هدر اتَرنت (Ethernet Header - L2)

طول این هدر **همیشه ثابت و ۱۴ بایت** است (بدون احتساب VLAN Tag):

Plaintext

```
 0                   6                   12        14 (Bytes)
 ┌───────────────────┬───────────────────┬──────────┐
 │ MAC Destination   │ MAC Source        │ EtherType│
 │ (6 Bytes)         │ (6 Bytes)         │ (2 Bytes)│
 └───────────────────┴───────────────────┴──────────┘
```

- **EtherType (۲ بایت):** مشخص می‌کنه لایه بعدی چیه!
    
    - `0x0800` $\rightarrow$ یعنی لایه بعدی **IPv4** است.
        
    - `0x86DD` $\rightarrow$ یعنی لایه بعدی **IPv6** است.
        
    - `0x0806` $\rightarrow$ یعنی لایه بعدی **ARP** است.
        
    - `0x8100` $\rightarrow$ یعنی **VLAN Tag** داریم (در ادامه توضیح داده شده).


### 🔹 لایه ۳: هدر IP (Internet Protocol - L3)

#### 1️⃣ حالت IPv4 (حداقل ۲۰ بایت - متغیر با Options)

Plaintext

```
 0               4               8               16              24              31 (Bits)
 ┌───────────────┬───────────────┬───────────────┬───────────────────────────────┐
 │ Version (4bit)│  IHL (4bit)   │  TOS (8bit)   │      Total Length (16bit)     │
 ├───────────────┴───────────────┼───────────────┴───────────────────────────────┤
 │     Identification (16bit)    │ Flags (3bit)  │    Fragment Offset (13bit)    │
 ├───────────────────────────────┼───────────────┬───────────────────────────────┤
 │      Time to Live (8bit)      │Protocol(8bit) │    Header Checksum (16bit)    │
 ├───────────────────────────────┴───────────────┴───────────────────────────────┤
 │                         Source IP Address (32bit / 4bytes)                    │
 ├───────────────────────────────────────────────────────────────────────────────┤
 │                      Destination IP Address (32bit / 4bytes)                  │
 └───────────────────────────────────────────────────────────────────────────────┘
```

- **IHL (Internet Header Length):** طول هدر IP را نشان می‌دهد (پایه آن ۴ بایت است). ضرب‌در ۴ طول واقعی را برحسب بایت می‌دهد. اگر IHL برابر 5 باشد $5 \times 4 = 20$ بایت (حالت استاندارد بدون Options).
    
- **Protocol (۱ بایت):** مشخص می‌کند لایه L4 چیست:
    
    - `6` $\rightarrow$ **TCP**
        
    - `17` $\rightarrow$ **UDP**
        
    - `1` $\rightarrow$ **ICMP** (مثل Ping)
        
- **Source/Destination IP:** آدرس ۳۲ بیتی مبدا و مقصد (مثلاً `192.168.1.1`).
    

#### 2️⃣ حالت IPv6 (ثابت ۴۰ بایت)

برعکس IPv4، هدر اصلی IPv6 طولش **ثابت (۴۰ بایت)** است که باعث پردازش بسیار سریع‌تر در پردازنده‌ها می‌شود. آدرس‌ها در این حالت ۱۲۸ بیتی (۱۶ بایت) هستند.

### 🔹 لایه ۴: هدر انتقال (Transport Layer - L4)

#### 1️⃣ حالت TCP (حداقل ۲۰ بایت - متغیر با Options)

پروتکل اتصال‌گرا (Connection-Oriented) با فلگ‌ها و کنترل جریان:

Plaintext

```
 0                               16              24              31 (Bits)
 ┌───────────────────────────────┬───────────────────────────────┐
 │      Source Port (16bit)      │   Destination Port (16bit)    │
 ├───────────────────────────────┴───────────────────────────────┤
 │                   Sequence Number (32bit)                     │
 ├───────────────────────────────────────────────────────────────┤
 │                Acknowledgment Number (32bit)                  │
 ├───────────────┬───────────────┬───────────────────────────────┤
 │ Data Offset   │ Reserved/Flags│          Window Size          │
 │   (4bits)     │   (12bits)    │            (16bit)            │
 ├───────────────┴───────────────┼───────────────────────────────┤
 │       Checksum (16bit)        │     Urgent Pointer (16bit)    │
 └───────────────────────────────┴───────────────────────────────┘
```

- **TCP Flags (خیلی مهم در فایروال‌ها):**
    
    - **SYN:** شروع Handshake و برقراری ارتباط.
        
    - **ACK:** تایید دریافت پکت.
        
    - **FIN / RST:** پایان یا ریست ناگهانی اتصال.
        
    - **PSH:** ارسال فوری داده به اپلیکیشن.
        

#### 2️⃣ حالت UDP (ثابت ۸ بایت - فوق‌العاده سبک)

Plaintext

```
 0                               16              31 (Bits)
 ┌───────────────────────────────┬───────────────────────────────┐
 │      Source Port (16bit)      │   Destination Port (16bit)    │
 ├───────────────────────────────┬───────────────────────────────┤
 │        Length (16bit)         │       Checksum (16bit)        │
 └───────────────────────────────┴───────────────────────────────┘
```

#### 3️⃣ حالت ICMP (پیام‌های کنترلی - حداقل ۸ بایت)

شامل `Type` و `Code` برای ابزارهایی مثل `ping` یا `traceroute`.
